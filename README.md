# UniversityCafeteria

ASP.NET Core MVC Day 1 exercise for a university cafeteria supply management system.

## Pages

- `/Cafeteria/Index`
- `/Cafeteria/Products`
- `/Cafeteria/Suppliers`
- `/Cafeteria/SupplyStatus`

The cafeteria pages use static HTML without models, a database, Entity Framework, ViewModels, or controller-provided data.

## Run

Requires the .NET 10 SDK.

```powershell
dotnet run --project "Supply Management System/UniversityCafeteria.csproj"
```

Alternatively, open `Supply Management System.slnx` in Visual Studio and run the project.
